## Important classroom distinction

The embedded practice lab is not SQL Server. It is a browser-based learning engine that supports the core beginner patterns taught here. Always use SSMS for final demonstrations of T-SQL-specific syntax, schemas, identities, `TOP`, `GO`, logins, users, roles, permissions, execution plans and server administration.
